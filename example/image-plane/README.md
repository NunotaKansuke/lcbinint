# Image-plane geometry

This example shows the `lcbinint.image` helper for visualizing binary-lens
geometry: caustics, critical curves, source position, and point-source image
positions.

Run without creating output files:

```bash
PYTHONPATH=build python example/image-plane/image_plane_geometry.py
```

The same walkthrough is available as a notebook:

```bash
jupyter notebook example/image-plane/image_plane_geometry.ipynb
```

Optionally save the figure:

```bash
PYTHONPATH=build python example/image-plane/image_plane_geometry.py --output image_plane_geometry.png
```
