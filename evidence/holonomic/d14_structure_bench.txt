PART 1 — THE IDENTITY  (verified exact)
--------------------------------------
scratchpad/verify_d14_structure.cpp builds D14 two ways on all 108 bench
geometries: production d14_coeffs(p_coeffs_in_R(...))  vs  the C3/G4/Z3 block
assembly.  Result:
    ratio (structural / production)  = 1.000000 on every coefficient
    worst relative mismatch          = 3.234e-28   (rand011)
    all 108 cases degree 14
That 3.2e-28 residual is the PRODUCTION degree-36 Iq/Jq route's own high-order
cancellation noise; the block route is the cleaner reference.
  D14(v) = 4096 * [ F6·G4^2 + 8·C3·(2C3^2 - 9v·G4)·Z3 - 432·v^2·Z3^2 ]
with, writing d=v-1, e=v-m, β=x^2+y^2-h:
  L  = v·d + a^2·e                          (deg 2)
  U  = a·e·d + x·L + a·v·β                  (deg 2)
  C3 = v·d^2 + a^2·e^2 + v(v+a^2)β + 2axv(3m-1-2v)   (deg 3, monic)
  G4 = U^2 + y^2·L^2 - 4aex·C3 - 4a^2 e^2 v(4x^2+y^2) (deg 4)
  B2 = [a·m + (x-a)·v]^2 + v^2(y^2-h)       (deg 2)
  Z3 = a^2(1-m) y^2 (v-m) · B2              (deg 3)
  F6 = C3^2 - 4v·G4                         (deg 6)

INTERPRETATION
--------------
* The block form is HEAVIER per Aberth node (~1.8x the flops of a 14-term Horner
  — memo §8 predicted this exactly).  On the common case (DD converges in ~3
  sweeps) that shows up as the isolated solve_d14 median regression to 0.83x.
* But it KILLS THE TAIL.  The expanded deg-14 vector carries ~1e-28 relative
  coefficient noise from the production degree-36 cancellation; near a
  near-multiple root cluster that noise is what pushed the old path onto the
  slow genuine-__float128 branch (p99 2.66 ms, max 3.0 ms on solve).  The block
  evaluator has no such noise -> the cluster resolves in tier-1 block-eval:
  solve p99 2.66 -> 0.89 ms (2.99x), radial_events p99 2.82 -> 1.00 ms (2.82x),
  epoch p99 3.96 -> 2.41 ms (1.64x), epoch max 4.18 -> 2.43 ms (1.72x).
* At epoch level the per-node cost regression washes out (D14 solve is a
  fraction of the epoch) and the tail win survives: epoch median 1.24 -> 1.20
  (1.03x), p90 2.21 -> 1.94 (1.14x), and every percentile non-regressing.
* This is exactly the profile decision-20 rewards: p90/p95/p99 must be
  non-regressing; here they strictly improve while the median is flat-to-better.
* Parity is clean (0/115), the identity is exact, and every existing tier /
  gate / warm-seed / fallback / soft-boundary path is untouched (flag OFF ->
  byte-identical; verified in the same process, strt == base to 1.00x).
