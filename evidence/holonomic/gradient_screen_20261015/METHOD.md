# Conservative screen and fold coordinates

The screen operates on the low-degree structured factors of Dhat rather than shifting an already-expanded D14 polynomial. This avoids severe cancellation in coefficient enclosures.

For a disk z=c+r*w, |w|<=1, a strict coefficient dominance inequality |a_k| > sum(j!=k)|a_j| proves exactly k roots by Rouche. Graeffe transforms can separate root moduli without changing the count inside the unit disk. Every comparison uses outward enclosures. No coefficient that can dominate after the final transform means no benefit from precision escalation, but still requires full geometric detection.

The first arithmetic tier carries a floating center, positive arithmetic majorant M and rounding depth n. The conservative error bound is 2*n*u/(1-2*n*u)*M. Unsupported/subnormal/overflow arithmetic is inconclusive. Subsequent tiers use outward binary64 intervals and the existing double-double ball arithmetic. Invalid floating-point environments disable the shortcut. Explicit successor/predecessor arithmetic handles signed zero and exceptional values.

For each occupied radial band [a,b], delta=(b-a)/resolution. The proof disk encloses the v=R^2 neighborhood with real bounds [a^2-delta^2,b^2] and imaginary half-width 2*(b+delta)*delta. The disk has additional factor-two padding. Opposite rigorous signs in disjoint brackets around existing physical events witness distinct real roots. Equality between witnessed real-root count and proven total root count excludes additional roots in this neighborhood. Failed whole-band proofs may use smaller cells; any unresolved region invokes the original detailed detector. This does not prove support outside existing occupied bands or bound gradient error.

Known mutually closest internal fold pairs are checked separately using an isolated two-root disk. This prevents a successful missing-root screen from skipping a close pair already present in topology. Exterior spans adjacent to real folds use R=R_fold +/- 2*b*sinh(y/2)^2, y=2*asinh(sqrt(distance/(2*b))). The actual endpoint and low radial remainder are retained to avoid cancellation. The interior uses the existing mixed polynomial/square-root seven-node rule. Complex pairs use R=Rc+b*sinh(y). Far spans retain ordinary treatment. These are coordinate and quadrature changes preserving the material-derivative identity, with no clipping or averaging of gradients.
