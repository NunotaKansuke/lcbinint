Reproduction
  bash evidence/holonomic/gradient_cell_attribution_phase73/run_phase73.sh

The script compiles independent direct fixed-R derivative/reference helpers,
regenerates caustic and rand035 per-cell radial reference series, performs the
same-node and LD term decomposition audits, writes summary.json and
cell_ranking.tsv, then updates SHA256SUMS. Its angular direct-QF integration
uses qf Sturm-isolated arcs; same-node angular audit uses 128 and 256 nodes.
Caustic radial GL uses 128/256/512/1024 nodes, angular 128, with an unregularized
run and a diagnostic-only forced theta=pi endpoint map. Rand035 base radial
series uses 48x1/128, 80x4/256, 112x8/512, 112x8/1024; extended cells 2/3/8
also use 112x8/1024, 128x16/1024, 160x32/1024. `ld_decomposition.cpp`
reuses the production Q8 sample/root-pair state only to split dvK and v*dK;
it is not the independent reference.

The included Phase72 reference translation unit emits GCC's
"control reaches end of non-void function" warning after its main is renamed
for inclusion. This warning is inherited from the research reference source;
the Phase73 diagnostic executables return success and produce the listed raw.

Reference limits
  Gauss-Legendre order sequences and finite-difference spreads are observed
  convergence checks, not formal error bounds. Near fold endpoints, distinct
  radial nodes are ultimately limited by binary64 R representation, so the
  highest radial order can be worse. The nonmonotone rand035 cell-2 160x32
  result and caustic 512/1024 drift are retained and explicitly not selected
  as reference truth. rand035 cell 11 has 48 source-invalid nodes and 207
  K-rule rejects in the Phase72 Q8 audit; its production whole sum is
  valid-only/incomplete.
