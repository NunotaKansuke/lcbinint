run_phase74.sh builds baseline and research-candidate diagnostics using the
same compiler flags, then pins all executions to CPU 0. The A/B epoch timer
includes epoch_value_adaptive/epoch_jacobian_adaptive (including topology),
but the one-case timing is a single observation and is not used as a speed
claim. The per-row corpus timing has one pass per binary in fixed order and is
diagnostic only. The research compile define does not alter a production
router/default.

Numerical policy/limitations
  Local p4 refinement and reciprocal residual/curvature/transversality screens
  are evaluated in __float128 and cross-checked against the existing D14
  positive-real event. This is a strict floating-point numerical gate, not an
  outward-rounded interval proof. The event remains chart_p4 unless all gates
  pass. No high-order projective contact fixture occurred in the scanned
  corpus; unit tests exercise the fail-closed branch predicates directly.
  Phase 73 independent FD and Gauss-Legendre sequences are observed
  convergence references, not formal bounds. rand035 cell 3 was not changed.
