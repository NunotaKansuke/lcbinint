# Finite-source auto calibration artifact

This directory is the frozen, reviewable result of the 2026-07-15/16
finite-source calibration campaign.  It is intentionally independent of the
runtime implementation added after the rules were frozen.

Files:

- `calibrated-rules.json`: exact feature definition, normalization constants,
  fitted coefficients, safety factor, buckets, and decision thresholds.
- `summary.json`: discovery, independent-validation, and long-timeout metrics.
- `source-profile-results.csv.gz`: one row per trusted source/profile result,
  including the reference, required bins on both grids, selected grid/bins, and
  VBM recommendation.  It contains 10,723 data rows (plus the header).
- `raw/*.tar.gz`: the complete original per-case/per-sample JSON output,
  including every fixed-bin value, timing, timeout, diagnostic, and VBM
  comparison.  These are deterministic archives of the three runs.
- `SHA256SUMS`: integrity hashes for all machine-readable artifacts.

The unpacked working copies (109 MB total) are:

- `.calibration-runs/finite-source-discovery-20260715/data`
- `.calibration-runs/finite-source-validation-20260716/data`
- `.calibration-runs/finite-source-high-mag-20260716/data`

Regenerate all files in this directory with:

```bash
python tests/diagnostics/finite_source_calibration_finalize.py \
  --discovery .calibration-runs/finite-source-discovery-20260715/data \
  --validation .calibration-runs/finite-source-validation-20260716/data \
  --high-magnification .calibration-runs/finite-source-high-mag-20260716/data \
  --output tests/diagnostics/results/finite-source-auto-20260716
```

The compact files are generated by the command above.  The raw archives were
created with sorted entries, zero timestamps, numeric owner/group zero, and
gzip timestamp suppression; `SHA256SUMS` verifies the checked-in copies.

The scientific rationale and sampling design are in
[`docs/finite-source-auto-calibration.md`](../../../../docs/finite-source-auto-calibration.md).
