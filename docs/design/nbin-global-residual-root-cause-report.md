## 根本原因と対応

### 1. 局所2行の誤差を全体の誤差としていた

端に近い2行の積分差だけでは、そこから離れた行にも続く平方根項の離散化誤差を表せない。残りの二階差分を足す処理も、端の切り分け位置によって残差が変わっていた。

内向きの無次元距離をt、格子間隔をhとし、行幅を `W(t)=a sqrt(t)+b t^(3/2)+...` と書く。通常の格子和に対する全体の端寄与を

`integral - grid_sum ≈ -h [a ζ(-1/2,η)+b ζ(-3/2,η)]`

として評価する。実際に適用されたBennett式15の重みの寄与を、元の各行について一度だけ差し引く。古い「残りの行の二階差分/24」は現在の候補には混ぜない。

Hurwitz ζはEuler–Maclaurinで評価する。[DLMF §25.11](https://dlmf.nist.gov/25.11)を参照。これは剰余上限ではない。独立な `sqrt(x) exp(-x)` のGamma積分について、位相7個×格子間隔2個の14条件で確認した。

### 2. 短い像端・空隙端を4行条件で落としていた

1行で生まれて次の行で別の像領域へつながる端は、4行のモデル条件を満たさない。その寄与を捨てると、像の端と空隙の端の符号の相殺が崩れる。

短い端、または4行目が既存の境界ブラケット幅を超えて二次モデルに反する場合だけ、局所の `g=0, g_x=0` を解く。`g=|lens_map(z)-source|²-rho²`。像の5次多項式を解き直す処理ではない。既存の行と幾何を再利用する。

### 3. レンズの極と境界交点の数値誤差

極にちょうど乗った外側点は `0*Inf` からNaNとなり、境界補正を無言でスキップしていた。既知のレンズ位置に一致する場合だけ、外側距離を+Infとして扱う。任意のNaNを外側に分類しない。

また、境界ブラケットの中点を交点とした系統誤差が、縦方向の誤差と偶然相殺していた。ブラケット内に収まるNewton補正を一度だけ行う。二分法を全面的に厳しくする処理ではない。問題のあった300行を独立な水平断面の六次多項式で照合し、300/300で交点由来の面積誤差が増えなかった。絶対面積欠陥の合計は5.61e-5→1.11e-5。

この2点は実験overlayの増光率計算自体を修正するため、修正後の値は保存済みmaster値と一致する必要はない。通常のmaster経路は未変更。残差診断のon/offでは同じ修正済み増光率が80/80完全一致した。

### 4. 同じ行間に2つの縦方向の極値が隠れる

nbin16の等質量例では、像端と空隙端が同じ行間にあり、観測されるrun数は1→1のままだった。その区間だけ境界を横方向 `y(x)` から追い、固定8点積分と補集合の端微分補正で評価する。既に見えている端や接合部から離れ、境界の移動量が大きい一つの行間に限定する。

独立な8点/16点評価の増光率差は約2.15e-9。全体のnbinを増やす処理、全caustic構築のやり直し、六次多項式のruntime求根は導入していない。

### 5. 空隙に像の8近傍接続を流用していた

新しいholdoutで、閉じた空隙を8近傍の整数セル接続が外部の空隙につないでいた。上側の端が存在しないことになり、その残差だけ落ちていた。

空隙の接続を、実際の境界交点から求めた連続区間の厳密な重なり判定に分離した。像のflood fillの8近傍は変更していない。追加のレンズ写像評価を伴わない接続修正で、この例の誤差は3.73e-4→6.47e-7に減った。

### 6. 格子点の間に収まった小さい像が丸ごと抜ける

別のholdoutでは、中心の像位置は既に求まっていたが、近傍の格子点がその像の外にあり、面積が0として扱われていた。残差推定だけを直すと、それまでの偶然の相殺がなくなって悪化する。

既存の中心像をトレース結果に保持し、格子上に代表点がない小さい正則像だけを、局所の上下端と固定16点の境界積分で追加評価する。粗い格子の占有点と局所領域が重なる場合は丸ごと追加せず未解決とする。局所Newtonが失敗した場合も未解決として記録し、古い全体処理へ戻らない。

この例で抜けた像の寄与は増光率6.3388079e-4。独立な8/16/32点の積分が一致し、修正後の誤差は2.51e-8。追加の5次多項式の求根は0。80条件中、この修正が実行されたのはnbin16の1条件だけ。

## 適用範囲と次に必要なこと

これは一様光源、追加成分細分化なしの単一格子についての符号付き残差候補。`certified=false`。任意の折り畳み・cusp・全像成分の完全性や、モデル剰余の厳密上限を証明していない。小さい像の局所修正も、既知の中心像と局所形状を使う診断であり、光源中心に存在しない全像成分の被覆証明ではない。

本番のnbinと受理条件は下げていない。追加5.8%は診断の費用で、総速度向上の実証ではない。次は残差の絶対値をそのまま「保証」と呼ばず、局所形状・未解決量・モデル剰余を使う受理判定を組み立て、初期nbin低減を含む費用を別途比較する。全体nbinを倍々に増やして収束を見る方法は採用しない。周辺減光と成分細分化への対応も残る。
