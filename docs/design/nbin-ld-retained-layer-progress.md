# LDの正確な分解と保持する半径積分

## 到達点と未完部分

実験overlayに `LimbLayerIntegral` とPythonの `LimbLayerIntegralState` を追加した。既存の輝度則・光源flux規格化を正確に分解し、必要な円盤半径だけを局所積分で追加する層。与えた円盤面積providerは、計算済み像状態を所有・再利用する契約。積分層自体はレンズ方程式を解かず、seed/fillも呼ばない。

**binaryの実際の面積状態との接続はまだない。** providerへ毎回独立な `binary_adaptive_area` を渡す構成は作っていない。この段階の評価回数削減は半径積分の比較であり、実レンズの総時間の高速化ではない。通常master経路は変更なし。

## 正確に扱うもの

既存実装は `B=1-c-d+c*mu+d*sqrt(mu)`、`mu=sqrt(1-r²/rho²)`。半径rの円盤の像面積をA(r)とすると、層積分の恒等式は

`flux=(1-c-d) A(rho)+integral_0^1 (2ct+d) A(rho sqrt(1-t^4)) dt`

となる。これは輝度則の近似ではなく、部分積分と `mu=t²` の正確な変数変換。source fluxも既存と同じ `pi*rho²*(1-c/3-d/5)`。

さらに `t=1-u²` とすると、円盤半径と重みは

- `r(u)=rho*u*sqrt((2-u²)*(1+(1-u²)²))`
- `w(u)=2u*(2c*(1-u²)+d)`

となる。光源縁のLD平方根項を除き、単一レンズ中心でA(r)~rになる場合のr=0の端も正則化する。r=0の面積は正確に0、外側円盤A(rho)は再利用。c=d=0なら外側円盤1回だけで終える。

## 数値近似と保持

u方向は埋め込みGauss7/Kronrod15積分。両則で同じ評価点を使い、差の2倍に円盤面積providerの誤差と丸め指標を足して誤差推定する。一般的な剰余保証ではない。内部のcaustic接触でA(r)が非滑らかになり得るため、全ての配置に対する受理保証を主張しない。`certified=false` を返す。

半径の評価値・誤差をmapで保持。同じ要求の再実行ではprovider呼び出し0。評価予算で停止してから再開すると、既存値を捨てず未達区間だけを分割する。要求を厳しくした場合、保持したprovider誤差が新しい予算を超える半径だけに追加精密化を要求する。provider側が像の状態を保持する必要があり、この層だけで幾何計算の再利用まで実現したとは扱わない。

新しい1区間の評価は15半径。二分には最大30新規半径が必要で、低次則ほど点共有は多くないが、滑らかな区間での評価回数が少ない。成功した区間は保持。現段階の小さな半径区間数では区間選択は単純走査であり、必要なら既存の優先キュー方式へ移せる。

## 独立検証と重さの確認

1. A(r)=pi*r²*(1+k*r²/rho²)、k=0,0.2,2、輝度係数4組の12条件を解析的なweighted fluxと比較。
2. 中心単一レンズA(r)=pi*r*sqrt(r²+4)、rho=0.01,0.3、LD係数3組の6条件を、元のsource-planeのpoint magnificationを輝度積分した80桁参照と比較。層の変換式を参照側では使わない。
3. 予算停止後の再開と一括計算がflux・provider評価数で完全一致。
4. 同じ要求で追加0。解析providerでは各半径1回。必要なprovider精度の引き上げも検証。
5. c=d=0はprovider1回だけ。C++回帰を追加し `unit_core` と `unit_boundary_support` は2/2成功。

初期の局所Simpsonでは単一レンズで60〜204円盤評価が必要だった。高次則では16〜46回になり、単一レンズ参照との差は最大4.95e-14。合成面積12条件では一様光源1回、LD16〜46回。タイミング倍率ではなく、同じ許容差の評価回数比較。実binaryでは1回の面積費用と内部接触の非滑らかさが違うので、この結果を総速度倍率にしない。

## 次の接続

外側円盤の像探索で得た成分と境界を保持し、追加半径に対して境界を局所追跡するproviderを設計する。半径変化で消える・現れる成分の判定と、新規区間だけの追加を明示する。16〜46回の独立seed/fillは実行しない。直接の像内輝度積分と比較し、円盤層方式の追加量が高ければ採用しない。
