# 共通誤差推定：過小評価の原因診断と修正

追補：過大評価と追加費用の削減は [nbin-shared-error-economy-report.md](nbin-shared-error-economy-report.md)。以下は前段v9の記録。

2026-10-13。branch `feature/boundary-error-and-discriminant-support`、基準HEAD `b51c00c566667fc2ed1fe640543219f480642002`。実験overlayだけを変更。通常scalarの増光率、seed、Bennett補正は変更していない。

## 結果

元の58条件で過小評価 **4→0件**。追加のlinear LD係数端 c=1 の6条件では1件が約1.1%過小評価となった。合計64条件で通常scalarとのbit一致、誤差推定による追加写像0。`certified=false`、`complete_error_model=false`を維持する。現在の入口は固定格子の増光率と誤差指標であり、適応細分化や自動受理を実装したものではない。

## 原因をどう分離したか

過小評価4件はすべてnbin128。保存済み独立参照を利用し、実際に保持した各runについて以下を検証専用のPython処理で計算した。

1. 同じ格子点・同じ交点で輝度だけ正確な式に置き換え、輝度テーブルの差を抽出。
2. 同じ内外セルの交点を独立のBrent法で高精度化し、境界位置の差を抽出。
3. その交点間をSciPyで水平積分し、内側方向の積分誤差を抽出。sin変換で平方根端を正則化。
4. 以上の補正後と独立全増光率参照との差を、行方向に残る誤差として分離。

これは保持したrun内の分解であり、全像の被覆証明ではない。各traceは粗い/fineが混在しないことと、保持した寄与が増光率を再構成することをassertした。今回4件は通常の追加component refinementが0である。

すべて増光率単位、符号は参照−計算値の補正方向。交点精度を全面的に上げても主因は解決しない。

## 修正1：内部の隙間・像端の寄与

旧cheap指標は像成分全体の上下端をfitし、run数が変わる場所には二階差分を置いていた。内部の隙間が開閉する平方根端の符号付き寄与はモデル化されていなかった。

小q uniformの診断では、外側端の寄与−1.9945e-5に対し、隙間端の寄与は−4.4033e-5。両者の合計−6.39785e-5が実際の差−6.39789e-5を説明した。既存の重い幾何診断は原因の確認だけに使用し、runtimeへ移植していない。

実行時には既に求めた左右交点fractionをrunごとに2double保持し、行の連続区間から局所端を見つける。空隙は連続区間の重なりで接続する。4行の既存幅から端位置と平方根項をfitし、共通endpoint momentで符号付き残差を追加する。

LDではこの空隙の幾何寄与をlimb brightness (1−c)で重み付けする。空隙付近のLD部分の一般的な特異性は未解決で、従来の局所接合部指標を残す。短い端・fit不能な端はその局所footprintだけ既存のzero-halo二階差分指標を用い、未解決と記録する。全体refillや追加のレンズ写像は行わない。

## 修正2：LDの外側端の関数形

正則な像端でsource depthを局所的に `g≈a t−b x²` とすると、uniform行幅はsqrt(t)型。一方、linear LDのsqrt(g)をx方向に積分した寄与はt型になる。

旧モデルは両者をまとめてsqrt二次式へfitしていた。これがLD pilot2件の行方向誤差を過小評価する主因だった。uniform同条件では元から符号付き外側残差が実誤差とよく一致していた。

既存のrun fluxを `(1−c)*geometric_width + LD_part` に分ける。端位置は同じ幾何幅のfitを共用し、uniform部分はt^(1/2),t^(3/2)、LD部分はt,t²のmomentで評価する。LDの整数べきmomentはBernoulli式から直接計算する。異なる積分器や半径別fillは追加していない。

行幅・flux・重みは一度の並べ替えと行集計で保持する。端ごとに全runを再走査する試作を削除し、接続graphも同じ行に複数runがある像成分だけ構築する。

## 残課題

c=1、小q、nbin512の1条件で指標6.4147e-6、実誤差6.4859e-6、約1.1%の過小評価。独立参照の安定性は1.8e-11で、不足約7.1e-8を参照の揺らぎでは説明できない。この条件の残差の詳細分解は未実施であり、輝度テーブル、内側fit剰余、空隙のLD特異項のいずれかと断定しない。

全64条件で `indicator<=tolerance<actual_error` はtolerance1e-5/1e-7とも0件。ただし標本上の観測であり、一般的な上限保証ではない。元の別geometry集合も今回の原因診断に利用したため、修正後の未使用holdoutとは呼ばない。

未発見像、任意のcusp・薄い像、model剰余、輝度テーブル全体の誤差、polar/d!=0は未保証。自動受理・標準設定には昇格していない。

次は同じ局所項を誤差の優先順位に使い、既存の行・交点・寄与を保持する共通の適応状態へ接続する。固定格子全体のnbin倍増による収束確認はruntimeに導入しない。追加c=1例の不足は局所モデルの未解決量として扱い、全体へ重い保証や一律倍率を追加しない。
