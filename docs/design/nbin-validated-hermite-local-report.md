# 局所Hermite積分の厳密上限：一様光源

## 結果と適用範囲

実験overlayに `validated_hermite_boundary.hpp` と診断binding `_validated_hermite_boundary` を追加。滑らかな単一境界x(y)について、存在・一意性、四階微分上限、端点求根と端点微分を含む積分区間を外向き丸めで評価する。既存の安い適応指標と分離し、通常の適応処理へはまだ入れていない。masterの既定経路も変更なし。

解析的な単一レンズの内外の境界8区間は、80桁解析積分を全て包含。binaryの5配置×3行間×左右＝30区間も全て局所保証が成立し、独立なSciPy積分と整合した。ただし後者の参照値自体は区間保証ではなく、参照積分の誤差指標も保存。像全体・像成分の見落とし・端の保証を達成したという結果ではない。

## 数学的な契約

g(x,y)=|lens_map(x,y)-source|²-rho² とする。与えた矩形でg_xが0を含まず、左右の辺で全てのyについてgが反対符号なら、各yに一意な根x(y)が存在する。極・非有限値・非対応丸めモード・不適切な矩形は拒否する。入力はbinary64で与えたパラメータの実数値。質量比から質量への変換も区間演算で行う。

Taylor係数a_n=x^(n)/n!を4次まで区間演算で再帰評価する。g(x(y+t),y+t)=0 のn次係数はg_x a_nと既知の低次係数からなるので、`a_n=-既知係数/g_x` で囲える。これは局所五次モデルの微分ではなく、矩形内の実際の暗黙境界の微分上限。

Hermite積分の剰余は `H^5 sup|x''''|/720`。Taylor係数では `H^5 sup|a_4|/30` となる。端点は区間Newtonで既に存在が証明された根を縮め、端点値と傾きも区間にしてHermite積分を評価。端点誤差と剰余を加えた区間を返す。

この保証は与えたグラフの積分について条件付きで成立する。他の境界や未発見成分が存在しないことは証明しない。IEEE通常演算、round-to-nearest、gradual underflow、fast-mathなしが前提。

## 過大評価の原因と修正

最初は既存の自然区間評価を使い、binary30区間中14区間だけが成立した。未解決区間だけを深さ4まで二分しても15区間までしか改善しなかった。成功区間は再評価せず保持した。これらの失敗記録も残した。

問題は矩形の広さだけではなく、レンズ写像で打ち消す項の区間依存性だった。左右の辺での符号判定を `g(x,y_mid)+g_y(x,Y)*(Y-y_mid)` の平均値形式へ替えたところ、同じ30矩形を追加細分化せず全て保証できた。区間勾配自体は矩形全体で評価するので、判定を緩めたわけではない。

## 指標との差とコスト

30区間で、厳密剰余上限/従来の局所モデル指標は中央値15.96、最大126232。モデル指標を下回る実誤差違反はこの小行列では0だったが、普遍性を意味しない。

局所保証1回の時間中央値は約68µs（Python呼び出しを含む単発計測、参考値）。安いモデル指標と同じ頻度で全区間へ入れると無視できない追加量になる。特に厳密上限をそのまま許容差に使うと、保守性が不要な細分化を生む。現段階では標準経路へ組み込まず、上限を狭くする表現の評価と、難しい区間の診断に使う。

## 誤差を分けた現状

|項目|現状|
|---|---|
|滑らかな一境界の端点誤差|区間Newtonと区間傾きで積分へ反映|
|滑らかな一境界の積分剰余|四階微分による局所上限を実装|
|像の端・消える隙間|u²変換の適応モデルはあるが、その剰余保証は未実装|
|像成分の見落とし|今回の局所証明の対象外|
|LD|未実装。局所境界の面積保証だけでは輝度積分の保証にならない|

安い指標だけで最終受理した結果を数学的保証付きとは呼べない。また、成功した局所証明を足しても、未保証の端領域や未発見像が残れば全体保証にはならない。`certified=false` を維持する。

## LDへの接続方針

LDでは像内の輝度が変化するため、一様面積の輪郭式に境界輝度を単純に掛けるだけでは不十分。半径rの光源円盤の像面積A(r)を使うなら、輝度B(r)について `flux=B(rho)A(rho)-integral A(r)B'(r)dr` が候補。光源縁の平方根特異性、入れ子円盤間の境界追跡再利用、半径方向の誤差配分を扱う必要がある。各半径でseed/fillを作り直す方式は避ける。

次の実装対象は先に端のu²変換後の局所保証。端点の暗黙関数を通常座標のx(y)と同じ式で扱うと微分が発散するため、変換後の関数へ証明を移す。LDの本実装はこの切り分けを保ち、全体保証とは独立に評価する。
