# 像全体の局所適応：実装・精度・総時間

## 到達点

実験overlayの `LensAdaptiveArea` で、正則区間だけでなく像の端と分岐・合流を含む一様光源の面積を局所適応化した。初期 `nbin=16` のseed・flood fill・境界記録を一度作り、その後は必要な境界区間だけを細分化する。通常のmaster経路と自動nbinの既定値は変更していない。

既存40条件と追加のレンズ配置20条件で、絶対増光率許容差1e-5、1e-7をそれぞれ60/60満たした。最大誤差は7.286e-6、8.909e-8。参照はVBMicrolensingのTol/RelTolを1e-10、1e-11にした二回の計算で、差も保存した。全条件で未解決0。ただし局所誤差モデルと像成分の被覆は数学的保証ではなく、`certified=false` を維持する。

## 面積を重複なく組み立てる

隣接行のrunを二部グラフでまとめ、各行間で外側の輪郭積分から内部の隙間を引く。現れる・消える隙間は負の端領域、物理的な像の両端は正の端領域として積分する。端は `g=|lens_map-source|²-rho²=0` と `g_x=0` を局所的に解き、`y=y_end±u²` に変換する。幅の平方根特異性を滑らかな被積分関数 `2u W` にする。

急な横移動では、端点勾配の符号に応じてx(y)とy(x)を切り替え、後者では部分積分を使う。双方の勾配が反転するなど対応を解決できない場合は未解決として返す。

適応結果はこの区分から計算した面積そのもの。既存Bennett増光率への上乗せではない。元のBennett補正と行記録は比較・再利用のために保持する。二重加算しない。

粗い格子で抜ける小さい中心像には、seed作成時に既に得た中心像位置を使う。局所Jacobianから像の大きさを予測し、そのスケールで境界と端を探す。追加の像位置の5次方程式求根は行わない。一方、境界の局所Newtonとlens map評価は追加され、総時間に含める。

## 保持と誤差モデル

- 交点・微分・成功した局所求根を保持。新しい求根は近い既存交点から予測する。
- 区間分割では既存中央点を引き継ぎ、新規四分点2点だけを評価する。
- 面積と誤差合計はlong doubleで差分更新し、処理区間は優先キューで選ぶ。細分化のたびの全区間走査を廃止。
- 同じ許容差の再実行では追加評価0。評価予算で停止しても状態を保持し、予算を増やして再開できる。
- 局所失敗時に全体の旧計算へ戻らない。未解決を明示する。

端点の値・微分によるHermite積分をI、中央の値と微分の予測残差をD、D'、区間長をHとすると、指標は

`E = (8/15) H |D| + (4/3) H² |D'| + 評価丸め誤差の指標`

とした。係数は局所五次Hermiteモデルの四階微分と非負Peano kernelから得たモデル上の上界であり、真の関数の剰余保証ではない。局所次数4を追加量予測に使い、子の誤差合計が親の半分を超える場合は予測次数2へ下げる。全体nbinを上げて増光率の収束差を見る方法ではない。

## 不具合の原因と修正履歴

旧参照精度、粗い弦からのNewton初期値、ほぼ垂直の境界、座標のulp以下の停止条件、極小像に粗い格子幅を使う端探索を分離して修正した。特に追加20配置の最初の検証では19成功・1未解決だった。極小像の端探索を局所像サイズに合わせ、再検証で20成功となった。追加配置はこの修正にも使ったため、未使用の独立holdoutや普遍的保証とは呼ばない。

値の中央残差だけのモデルでは1条件で実誤差1.0011e-5となった。既に評価していた中央微分の形状変化項を加え、許容差を緩めず解消した。過去の失敗出力は保存している。

## 総時間

**比較対象の訂正：** この節の固定版にも `LCBININT_DIAGNOSTIC_DISABLE_COMPONENT_REFINEMENT=1` が掛かり、既存の成分別追加細分化を無効にしていた。通常masterとの比較ではなく、以下の時間差を従来masterに対する高速化として使ってはいけない。通常経路での性能比較は未実施。

Releaseビルド、同じ実験境界kernel、1 thread。60条件の各呼び出しでs/qの配置を変え、静的causticキャッシュの連続再利用を避けた。scalar APIでseed生成・粗いfill・適応処理を含むバッチ時間を7回測定し中央値を採用。Pythonへの全行トレース出力は時間に含めない。

|方式|60条件の時間|1e-5達成|1e-7達成|
|---|---:|---:|---:|
|固定64|0.10910 s|5/60|0/60|
|固定128|0.16761 s|10/60|0/60|
|固定256|0.36670 s|26/60|1/60|
|適応・初期16・許容差1e-5|0.12721 s|60/60|—|
|適応・初期16・許容差1e-7|0.13962 s|—|60/60|

1e-5適応は固定128より24.1%短く、1e-7適応は固定256より61.9%短かった。固定版はそれぞれ多くの条件で許容差を満たしていないため、同じ達成精度の速度倍率とは解釈しない。優先キュー化前の同じ60条件の1e-7適応は0.23266 sで、細分化管理の全走査が厳しい許容差で重かった。別測定間の参考比較であり、生の7回測定値を両方保存した。

## 再現・検証

`tests/diagnostics/results/recal2026/` の以下を保存。

- `adaptive-image-area-v6/`: 40条件、1e-5から1e-7への状態継続、同じ要求の追加ゼロ。
- `adaptive-image-area-holdout-v3/`: 追加20配置、参照値と精度判定。
- `adaptive-image-area-resume-v2/`: 5条件で2分割後に予算停止し再開。一括計算と面積・評価点数・map評価数が完全一致。
- `adaptive-image-area-cost-v4/`: 60条件の総時間7回、各方式の実誤差、ソースsnapshot・hash・再現コマンド。

C++回帰は独立な円盤・単一レンズ環の既知面積、quartic積分、予算再開、追加ゼロ、混在階層拒否を含む。`unit_core` と `unit_boundary_support` は通常・逐次seed設定の両方で2/2成功。

Python実験APIは `_adaptive_image_area_from_trace(...).refine(area_tolerance,budget)` と `binary_adaptive_area(...,initial_bins=16,absolute_tolerance=...)`。後者も既存診断を必要とするため `LCBININT_BOUNDARY_DIAGNOSTICS=1` と `LCBININT_DIAGNOSTIC_DISABLE_COMPONENT_REFINEMENT=1` を設定する。失敗を含む返り値の `estimated_target_met` を必ず確認する。

## 残り

対象はbinary、一様光源、単一階層Cartesianのみ。混在階層は拒否する。粗いsupportが全像成分を発見したという一般保証や真の積分剰余上限はない。LD、relative/mixed tolerance、未解決箇所だけの追加修復、別母集団での受理指標検証を経てから通常経路への採用を判断する。次は既存面積状態を保ったままLDの寄与と誤差配分へ接続する設計を行う。

局所剰余の後続実装：[局所Hermite積分の厳密上限](nbin-validated-hermite-local-report.md)。
