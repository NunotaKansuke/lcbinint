# Effects cookbook and runnable examples

This page is the copy-and-run companion to the [user guide](user-guide.md).
It follows the useful VBMicrolensing documentation pattern: choose the
physical effect you need, copy a small working example, and compare its shape
with an observed output before composing effects in a fit.

The complete source for every recipe below lives in
[`example/high-order-effects/high_order_effects.py`](../example/high-order-effects/high_order_effects.py).
Run it from a source checkout after building the extension:

```sh
PYTHONPATH=build python example/high-order-effects/high_order_effects.py
```

The output below was generated by that command. Values are rounded to six
decimal places; treat them as a smoke-test illustration, not a cross-platform
numerical reference.

## 1. Binary lens baseline

Build one callable and evaluate a vector of epochs. This is the foundation for
all later examples.

```python
times = 2459000.0 + np.array([-2.0, 0.0, 2.0])
params = dict(
    t0=2459000.0, tE=20.0, u0=0.1, alpha=0.3,
    s=0.9, q=0.02, rho=0.0,
)
curve = lcbinint.LightCurve()
print(curve(times, params))
```

```text
[5.882842, 9.228517, 7.981658]
```

Set `rho > 0` to request finite-source evaluation. Attach
`LimbDarkening.linear(u)` to the callable when the source is limb darkened;
use `curve.info(times, params)` to see which numerical method was selected.

## 2. Annual and terrestrial parallax

Annual parallax is opt-in: `piEN` and `piEE` alone do nothing until the model
enables it and supplies a sky coordinate and reference epoch.

```python
model = lcbinint.Model(
    parallax=True,
    sky=lcbinint.obs.SkyCoord(270.0, -30.0),
    t_ref=2459000.0,
)
curve = lcbinint.LightCurve(model=model)
params.update(piEN=0.1, piEE=0.05)
print(curve(times, params))
```

```text
[5.883169, 9.228517, 7.983076]
```

Terrestrial parallax adds `terrestrial=True` *and* a ground observatory.
Latitude is north-positive; longitude is east-positive.

```python
ground_model = lcbinint.Model(
    parallax=True, terrestrial=True,
    sky=lcbinint.obs.SkyCoord(270.0, -30.0), t_ref=2459000.0,
)
ground = lcbinint.LightCurve(
    model=ground_model,
    site=lcbinint.obs.Site("ground", -29.0, 70.7),
)
print(ground(times, params))
```

```text
[5.883276, 9.228500, 7.982860]
```

## 3. Space observatory parallax

Use the same annual-parallax model and give only the space curve a satellite
ephemeris. The required columns are `JD, RA_deg, Dec_deg, distance_AU` and
times must be strictly increasing.

```python
table = np.array([
    [2458997.0, 0.0, 0.0, 0.010],
    [2459000.0, 0.0, 0.0, 0.012],
    [2459003.0, 0.0, 0.0, 0.014],
])
space = lcbinint.LightCurve(
    model=model,
    site=lcbinint.obs.Site("space", table),
)
print(space(times, params))
```

```text
[5.887589, 9.316789, 8.082642]
```

Sharing a `Model` is intentional: it keeps event physics identical while each
`LightCurve` retains its own observatory. See the [API reference](python-api.md)
for the satellite-table convention.

## 4. Lens orbital motion

Lens orbital motion changes the projected lens geometry with time. Set the
model mode, reference epoch, and its per-call orbital parameters.

```python
orbit = lcbinint.LightCurve(
    model=lcbinint.Model(orbital_motion="circular", t_ref=2459000.0)
)
orbit_params = dict(params, g1=0.004, g2=0.011, g3=0.006)
print(orbit(times, orbit_params))
```

```text
[5.921636, 9.228517, 7.928687]
```

Choose `orbital_motion="kepler"` when the parameters include the Keplerian
terms `lom_szs` and `lom_ar`. The runnable
[`example/kepler-lom/`](../example/kepler-lom/) demonstrates its reference-time
convention and optional VBM comparison.

## 5. Xallarap (source orbital motion)

Xallarap is also selected on the model/callable. The element form below uses a
circular source orbit; values use a local time origin for readability.

```python
xallarap = lcbinint.LightCurve(xallarap="circular_elements")
xallarap_params = dict(
    t0=0.0, tE=20.0, u0=0.3, alpha=0.5, s=1.0, q=0.1, rho=0.0,
    xi_1=0.25, xi_2=-0.1, period_xa=35.0, inc_xa=1.1,
)
print(xallarap(np.array([-5.0, 0.0, 5.0]), xallarap_params))
```

```text
[2.129704, 2.868097, 3.013893]
```

Other supported choices are `orbital_elements`, `circular_velocity`, and
`kepler_velocity`. Their parameter sets are listed in the
[Python API reference](python-api.md).

## 6. Binary sources

A binary-source model combines two source trajectories. `q_source` is the
second/first source-flux ratio; the simple form specifies a second closest
approach.

```python
binary_source = lcbinint.LightCurve(
    source="binary", xallarap="circular_elements"
)
print(binary_source(
    np.array([-5.0, 0.0, 5.0]),
    dict(xallarap_params, q_source=0.5, t0_2=1.0, u0_2=-0.2),
))
```

```text
[2.085968, 4.340170, 3.253177]
```

For coupled xallarap, replace `t0_2`/`u0_2` with a positive `q_mass`. The
secondary xallarap amplitude is then derived internally.

## 7. Triple lenses

Choose `lens="triple"` and provide a positive `q2` at evaluation. `sep2` and
`ang` describe the second companion; angles are radians.

```python
triple = lcbinint.LightCurve(lens="triple")
triple_params = dict(
    t0=0.0, tE=1.0, u0=0.01, alpha=0.5, s=1.0, q=1e-3,
    q2=1e-4, sep2=0.5, ang=1.2, rho=0.0,
)
print(triple(np.array([-0.1, 0.0, 0.2]), triple_params))
```

```text
[ 9.659443, 98.719385,  5.125034]
```

For finite triple sources, use the same `rho`, `Options`, and
`LightCurve.info()` workflow as for binary sources. Inspect
`finite_source_converged` when requesting an explicit accuracy budget.
